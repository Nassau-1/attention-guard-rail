# MVP

## Goal

Create a free personal iPhone focus app that makes the home screen boring, textual, and intentional.

## First Version

- top widget: time and day
- launcher widget: text rows for selected apps
- app: simple setup and focus tabs
- intentional opening flow: 15-second visual delay and chosen session duration
- Screen Time permission request
- schedule model for recurring focus windows

## Next Version

- real `FamilyActivityPicker` app/category selection
- persisted launcher configuration
- temporary unshielding per app after the delay
- re-shield after selected session duration
- HealthKit card for metrics that Bevel writes to Apple Health
- weather card with explicit location permission

## Non-Goals

- paid subscription
- cloud backend
- social features
- replacing iOS SpringBoard
- reading private data from Bevel directly
